# Source provenance

The evaluation uses the owner's committed nicotineplus-plugins source at commit
84afaf401b29753b6810e4f92f253e0d28637dbf, Git tree
60e59671ae0973188ae90ac46f7cfec1c06bfd8f. The two disposable upstreams have
different initial commit IDs but that identical source tree. The owner's
pending local changes are excluded from this experimental baseline and preserved.

Keep the original per-file headers and PLUGININFO author metadata with any
source snapshots. The frozen repository root contains no repository-wide
LICENSE/COPYING file; this evaluation does not assign a new license to that
source. The reference corrections and model patches are identified separately
from the original files.

The Hermes runtime is executed from its pinned local container image, with
the project-test dependency image identified in the protocol and evidence.
Private profile/authentication stores, environment files, Docker inspect
environment values and binary session databases are not public evidence.

Full normal-profile context and locally excluded project instructions may
remain private. Their hashes and the disclosed profile differences identify
the evaluation conditions. This limits byte-for-byte public replay of the
complete everyday profile; the bug reproductions, behavior checks, reference
corrections and captured patch/test evidence remain independently reviewable.
